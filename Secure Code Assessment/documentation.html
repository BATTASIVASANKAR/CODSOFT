How to Use the Scanner

Step 01

Upload or Paste Source Code

Drag and drop a .py, .js, .java, .cpp, or .php file, or choose from the built-in vulnerable sample code buttons.

Step 02

Execute Static Analysis

Click "Run SAST Scan". The browser rule engine scans line-by-line using pattern matchers and regex AST rules.

Step 03

Inspect & Remediate

Click findings to jump to exact code lines. Review the risk explanation, fix guidance, and secure replacement code.

Step 04

Export Audit Report

Navigate to Vulnerability Report to view Chart.js severity graphs and download an official formatted PDF report.

Severity Rating Matrix

CRITICAL (25 Points)

Direct Remote Code Execution (RCE), SQL Injection, hardcoded production secrets, or unescaped command injection.

HIGH (15 Points)

Cross-Site Scripting (XSS), path traversal file read, unsafe deserialization, or broken access controls.

MEDIUM (8 Points)

Weak password hashing (MD5/SHA1), debug mode enabled in production, or disabled TLS certificate verification.

LOW (3 Points)

Sensitive information printed to console logs or non-critical configuration misconfigurations.

OWASP Top 10 (2021) Security Mapping

OWASP Category Description Rule Pattern Covered
A01:2021 - Broken Access Control Unauthorized file access & directory traversal flaws. RULE_PATH_TRAVERSAL

A03:2021 - Injection SQL Injection, Command Injection, XSS, and eval() functions. RULE_SQLI_STRING_CONCAT, RULE_CMD_INJECTION_OS

A07:2021 - Identification & Auth Failures Plaintext hardcoded passwords, API keys, and secret tokens. RULE_HARDCODED_SECRET_01, RULE_HARDCODED_PASS_02
