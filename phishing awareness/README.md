# Phishing Awareness Program

A simple, clean, and responsive static website that teaches users about phishing, its types, how to identify it, and how to stay safe.

## Project Structure
```
project/
│── index.html
│── css/
│   └── style.css
│── js/
│   └── script.js
│── images/   (optional for future assets)
└── README.md
```

## Features
- **Responsive design** – works on desktop and mobile devices.
- **Navigation bar** with a mobile hamburger menu.
- **Sections** covering:
  - Home
  - What is Phishing?
  - Types of Phishing
  - How to Identify Phishing
  - Prevention Tips
  - Contact form (frontend‑only).
- **Smooth scrolling** between sections.
- **Simple form handling** – shows an alert upon submission.

## How to Run
1. Open `index.html` in any modern web browser.
2. No server or build step is required – all assets are static.

## Customisation
- Edit the content directly in `index.html`.
- Update styles in `css/style.css`.
- Extend front‑end behaviour in `js/script.js`.
